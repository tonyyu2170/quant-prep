## Constraints that bite (read before authoring anything)

1. **Path enumeration is dead for ruin — this corrects spec §5's two brute cells.** A walk on `{0..N}` survives step `D` with probability decaying like `cos(π/(N+1))^D` (slowest eigenmode of the absorbing transition matrix). Even `N=2` needs depth ≈ 40 for a `< 1e-12` tail — `2^40` sequences — and `N=5` needs depth ≈ 193 → `2^193`. Truncated enumeration cannot reach `verify.py`'s unscaled `1e-9` discipline at any feasible depth, so the `brute()` slot carries an **independent numpy linear solve** of the absorption system instead (matrix inversion vs the template's difference-equation algebra is genuine double-entry; Task 1 Step 3 shows the reference pattern).

2. **`verify.py:52` compares `brute()` output ABSOLUTELY at `1e-9` — no scaling.** A linear solve's error is ~`κ·eps` relative with `κ((I−Q)) ≈ (2N/π)²` for fair walks. Keep barrier sizes ≤ ~700 states: at `N=700`, error ≈ `(2·700/π)²·2.2e-16 ≈ 4e-11` on probability-magnitude answers — a ~25× margin under the absolute bound. Never route a *duration* through `brute()`: at magnitude ~1e3 the same relative precision leaves only ~100× margin and drifts toward flakiness — duration answers are always `montecarlo`-method. If a template genuinely needs larger barriers, re-derive the margin before committing the range.

3. **Monte Carlo-method problems floor probability-shaped answers at 0.1, not 0.01** — B4's measured constraint 10 carried forward unchanged. `verify.py:44` requires `3·se <= bound/2` with `bound = 0.005·|answer|`; for a Bernoulli estimate that is `N >= (1−p)/(6.94e-7·p)` — at the batch floor `p=0.01` that is ~144M trials (infeasible), at `p=0.1` it is ~13M (comfortable inside the suite's 15M-trial convention). Every `montecarlo` problem whose answer is a probability enforces `[0.1, 0.99]` through its constraint helper. `brute`-method ruin problems keep `[0.01, 0.99]`.

4. **Duration MC trial sizing is per-template, computed not inherited.** For a sample mean, `se = σ/√N`, so the noise bound requires `N ≈ (1200·σ/E[T])²`. Pilot-measure `σ/E[T]` while drafting each duration template (fair-walk absorption times sit near σ/E ≈ 1). At ratio ≤ 2, `trials=8_000_000` clears with margin (`3·se/E ≈ 1.3e-3 < 2.5e-3`). Simulate walkers vectorized in lockstep (positions array stepped until all absorbed) — cost is `trials × E[T]` ops, which is why duration templates also cap `E[T] <= 600` via constraint (keeps total work ~1e9 vectorized ops, seconds-scale). The global `1e4` ceiling stays satisfied trivially.

5. **One-barrier drift simulations stop walkers at a safe upper cutoff.** Stopping at `+K` undercounts the touch/reach probability by at most `P(walk ever goes from K down past −b)` = `(q/p)^{K+b}` under upward drift. Templates keep drift meaningful (`winPct ≥ 55`, so `q/p ≤ 9/11 ≈ 0.818`); `K = 150` then gives bias `< 1e-14`. State the cutoff and its bound in the solver's docstring; never truncate without one.

6. **Cancellation guards on the unfair-duration family.** `E[T] = [i − N·Π]/(q−p)` (with `Π` the success probability from `i`) cancels catastrophically as `p → q`, and `b/(p−q)` blows up the same way. Both templates constrain `|winPct − 50| ≥ 2` (percentage-point params make this a clean integer guard). The independent checks genuinely police the result — linalg/MC are different paths, not rearrangements.

7. **Probability-shaped answers are constrained into `[floor, 0.99]` — the cap is new this batch.** Certainty/impossibility draws are natural here and banned: fair-game "ever-hit" questions (answer exactly 1) do not exist in the inventory, and no legal draw may produce a probability outside the band. Duration/parameter answers are exempt from the 0.99 cap but inherit `≤ 1e4` (and constraint 4's practical cap where MC-checked).

8. **Sub-1e-6 derived hygiene — audit every key, not just `answerKey`.** `emit.ts:46` floors every `params`/`derived` value at `1e-6`. Unfair templates' powers like `(q/p)^N` stay module-LOCAL exactly as B4's `qToN` did; the `|p−q| ≥ 0.02` guard keeps `Π`-family intermediates ≥ ~0.04, but the audit is over the full legal draw space regardless.

9. **`printed-precision.test.ts` gates WHEN a topic joins `TOPICS` (line 13), not whether.** Its `MIN_CHECKED_PER_TOPIC = 1000` assertion fails immediately for a topic with too few problems: one exemplar × 200 seeds × ~4 chains ≈ 800 < 1000 (B4's measured precedent). `"probability/ruin"` joins in Task 2 once 8 problems exist; `"probability/geometric"` joins in Task 5 where all 8 L1 land in one task.

10. **Registry sum and prose-claims coverage are equality assertions that break CI on first registration if not extended in the same commit.** `registry.test.ts:34` sums topic counts against `PROBLEMS.length`; `prose-claims.test.ts:1007`'s `CLAIMED_TOPICS` list drives `expect(Object.keys(CLAIMS).sort()).toEqual(shipped)`. Create `verification/solvers/ruin.py`:

```python
"""Independent Python counterparts for content/problems/ruin/*.
exact(): re-derives every TS `derived` value in plain float arithmetic (double-entry), same
convention as bayes/counting/ev_variance/distributions.
brute()/simulate(): recompute the ANSWER by an independent path per spec §5 (as corrected by
plan constraint 1) — a numpy absorption-system solve for two-barrier probabilities, Monte
Carlo walkers for durations, drift touches, and doubling sessions."""

import numpy as np


def fair_reach_goal_exact(p):
    start, goal = int(p["startChips"]), int(p["goalChips"])
    frac = start / goal
    return {"frac": frac, "ruinProb": 1 - frac, "oppStack": goal - start}


def fair_reach_goal_brute(p):
    """Solve x = Qx + R over interior states 1..goal-1 numerically — matrix inversion rather
    than the difference-equation algebra behind start/goal, which is what makes this
    independent of exact()."""
    start, goal = int(p["startChips"]), int(p["goalChips"])
    m = goal - 1
    A = np.eye(m)
    b = np.zeros(m)
    for row in range(1, m):
        A[row, row - 1] -= 0.5
    for row in range(m - 1):
        A[row, row + 1] -= 0.5
    b[m - 1] = 0.5  # neighbour above the top interior state is the absorbing goal
    return float(np.linalg.solve(A, b)[start - 1])


SOLVERS = {
    "ruin/fair-reach-goal": {"exact": fair_reach_goal_exact, "brute": fair_reach_goal_brute},
}
```
